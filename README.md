## Projetos principais

### Barthy Web Studio V2

Site institucional e portfólio profissional criado para apresentar projetos, soluções digitais e competências em desenvolvimento web.

A aplicação utiliza React e TypeScript, componentes reutilizáveis, temas claro e escuro, acessibilidade, formulário de briefing, verificações automatizadas e progressive enhancement com fallback visual.

[Ver repositório](https://github.com/g4brielbr4sil/barthy-web-studio-v2)

### Hermes Command Center

Aplicação Full Stack autoral para centralizar CRM, pipeline, finanças, tarefas, rotina, estudos, relatórios, aprovações, memória e integrações em um ambiente operacional privado.

**Stack:** React, TypeScript, Python, FastAPI, SQLAlchemy, SQLite, Docker, Ubuntu, Amazon Lightsail e Cloudflare Pages.

[Acessar interface protegida](https://hermes-agent-01l.pages.dev/)

O repositório é privado porque contém lógica operacional e contexto pessoal.

### Levens Qualifica | PNQC

Plataforma educacional desenvolvida para organizar a formação de cuidadores em cursos, módulos, aulas, progresso e avaliações.

O projeto existente utiliza React, TypeScript, Vite, Supabase Auth, PostgreSQL e Cloudflare Pages. Essa menção descreve a implementação do PNQC e não representa a stack definida para novos projetos.

[Acessar aplicação](https://levens-qualifica-pnqc.pages.dev/)

O código permanece privado por segurança e propriedade intelectual.

### Barthy Web Studio V1

Primeira versão do site institucional da Barthy, com apresentação comercial, catálogo de soluções, sistemas, pacotes e formulário conectado ao Hermes ou ao WhatsApp.

[Acessar aplicação](https://barthy-web-studio.pages.dev/)  
[Ver repositório](https://github.com/g4brielbr4sil/barthy-web-studio)
